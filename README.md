<div dir="rtl">

هر نمونه‌ای که فرستاده می‌شود، به‌صورت یک **سایت کامل و جداگانه** با موشن‌گرافیک و تعاملات حرفه‌ای ساخته می‌شود.
طرح‌ها با هم **قاطی نمی‌شوند**؛ هر کدام پوشهٔ خودش را دارد. در مرحلهٔ بعد بهترین بخش‌ها را با هم ترکیب می‌کنیم.

## Structure

```
index.html                 hub — links to every design
site/                      NetRate landing site: src/ (template, i18n, config, scenes, css, js), app/ (the app demo),
                           assets/ (fonts, posters, icons), tools/ (sync, posters, brand assets, build, artifact, qa)
hub/                       hub styles + preview images
designs/01-byondbites/     Design 01 (self-contained: html, css, js, img, fonts)
designs/02-fitraho/        Design 02 (self-contained)
references/                the original reference images, one folder per design
vendor/                    shared libraries only (GSAP 3.15, Lenis 1.3)
tools/build_artifacts.py   builds dist/<design>/ for claude.ai artifacts (CDN libs, Google Fonts)
tools/qa/                  reference-fidelity helpers (full-page screenshot + side-by-side sheets)
DESIGNS.md                 design registry — palettes, type, measured layout, sections, motion
CLAUDE.md                  working rules for future sessions
```

The reference designs need no build step — everything (fonts, images, libraries) is in the repo and works offline.
The NetRate site has a small stdlib-Python build: `python3 -I site/tools/build.py` → `site/public/` (not committed),
then serve it (`python3 -m http.server 8092 --directory site/public`) — the live app needs http, not `file://`.
The artifact copies in `dist/` are generated by `python3 -I tools/build_artifacts.py` and are not committed.
